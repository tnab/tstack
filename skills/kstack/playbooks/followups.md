# Follow-ups

Deliver an accurate view of outstanding actions and changes to their status.

1. Use [followups](../../followups/SKILL.md) with the records, any existing register, and the applicable cutoff. Preserve IDs and separate proposals, requests, assignments, and accepted commitments.
2. Investigate a material status gap with [search](../../search/SKILL.md) only when it is within scope. An unanswered message does not prove acceptance or completion.
3. If updates are authorized, reconcile existing entries before writing, then reread the saved record. Otherwise deliver proposed changes. Repeated execution must not duplicate actions.
4. Verify the unresolved items and finish the result through [write](../../write/SKILL.md).

Done when status is supported by evidence and outstanding ownership, deadlines, and blockers are clear. Flagging a follow-up does not authorize messaging its owner or creating a reminder.
